最佳实践

✅ DO

  • • 使用定义的颜色和间距
  • • 确保色彩对比度充足
  • • 提供清晰的焦点指示
  • • 使用语义化 HTML
  • • 在移动设备上测试

❌ DON'T

  • • 使用任意颜色
  • • 忽视焦点状态
  • • 过度使用动画
  • • 创建过小的触摸目标
  • • 忽视深色模式
